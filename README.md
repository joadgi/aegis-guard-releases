# Aegis Guard: downloads

Installers and automatic updates for **Aegis Guard**, a lightweight Windows security and PC-care app: malware scanning, Download Guard, Security Checkup, startup and junk cleanup, and an AI assistant.

## Install

1. Open the [latest release](https://github.com/joadgi/aegis-guard-releases/releases/latest).
2. Download `Aegis.Guard.Setup.<version>.exe` and run it. No admin rights are needed.
3. Windows may show "Windows protected your PC" because the installer isn't code-signed yet. Click **More info**, then **Run anyway**.

Silent install for IT deployment: `"Aegis.Guard.Setup.<version>.exe" /S`

## Updates

Installed copies check this page automatically and update themselves. You don't need to do anything.

This repository contains release files only.
